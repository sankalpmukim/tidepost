Privacy

Tidepost is a personal email client. Mail is fetched from your Gmail or Microsoft account using OAuth and stored on the server that runs the app so it can show lists, search, and drafts.

OAuth tokens are encrypted at rest. Thread text is sent to Anthropic only if an API key is configured and you ask for a brief, draft, or plan.

You can disconnect an account at any time from Tidepost settings. Questions: sankalpmukim@gmail.com
